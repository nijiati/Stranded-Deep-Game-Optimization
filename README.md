# 《Stranded Deep》游戏优化包 —— 功能介绍

**【汉化】**

完整简体中文，界面、物品、提示全部汉化，装完即用，不需要额外设置。

**【联机】**

- 局域网直连，不依赖 Steam 服务器，延迟低、更稳定
- 切出窗口不会掉线，回来继续玩
- 同步提速，加载更快
- 修复“第二局加入卡在 0%”的问题
- 自带游戏内语音，按住 V 说话，不用开第三方语音软件

**【其他优化】**

- 自动存档：每 5 分钟存一次，出意外不丢进度
- 一键回档：随时退回前 3 次存档，选错也能找回
- 农田自动灌溉：出门回来农田不会干死
- 整格搬运：Shift + 点击，整箱物品一次搬完
- 上船辅助：在水里也能顺利爬上船
- 倒地自救：背包里有绷带，倒地 3 秒后自己站起来
- 沉船可拾取：沉船里的轮胎、铁桶可以捡走
- 开船音乐：上船自动切歌，只自己听得到

**【安装】**

三步，约 3 分钟：装汉化 → 放两个 dll → 进游戏按 F1。

**【注意】**

- 需要 Steam 正版游戏，仅支持 Windows
- 所有功能在 F1 界面里开关，按键可自由修改
- 不联网、不上传任何数据
- 游戏更新后需重跑一次汉化
